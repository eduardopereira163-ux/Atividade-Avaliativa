 Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html`.
3. Execute o projeto em um servidor local, como o Live Server.
4. Na primeira página, informe o CEP e a cidade.
5. Clique em **Consultar Endereço**.
6. Confira os dados do endereço na página de resultado.
7. Se a consulta for válida, clique em **Abrir no Google Maps**.
8. Para fazer outra consulta, clique em **Fazer nova consulta**.
